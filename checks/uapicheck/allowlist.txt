# uapicheck allowlist: differences between the 5.4 headers (ref/5.4.txt) and
# the 6.12 tree, each with the reason it is accepted.
#
#   KIND[@arch]  KEY[|KEY...]  STATUS  REASON
#
# Columns are separated by two or more spaces (or a tab).
#
# KIND  IOC DEF ENUM (one namespace: an ioctl #define that 6.12 turned into an
#       enumerator is the same name), SIZE ALIGN OFF FSIZE BITW, or * for all
# KEY   fnmatch pattern on the name; struct members are "struct x.member",
#       "struct x|struct x.*" covers a whole struct
# STATUS
#   ok     intended or harmless (the reason says why)
#   known  a real difference that still needs a fix: the check passes and
#          prints it as a warning, so it stays visible until the fix lands
#   =NAME  renamed: the 5.4 value of KEY must be the 6.12 value of NAME
#          (=.member for another member of the same struct); checked, a
#          mismatch fails
# A rule that matches no difference any more is reported (remove it).

# ---- terminators of append-only enums: they grow with every new member;
# the members themselves are compared one by one
ENUM  *_MAX|*_AFTER_LAST|*_LAST|NUM_*|MAX_NL80211_*|__*_AFTER_LAST  ok  enum terminator: grows with new members, every 5.4 member is checked on its own
DEF   IPA_CLIENT_MAX|IPA_HW_MAX|IPA_HDR_PROC_MAX|IPA_EVENT_MAX|IPA_EVENT_MAX_NUM  ok  enum terminator (#define): new IPA clients, HW versions, proc types and events appended
DEF   KGSL_PERFCOUNTER_GROUP_MAX|AUDIO_MAX_COMMON_IOCTL_NUM|V4L2_CID_LASTP1  ok  terminator: new perfcounter groups / common audio ioctls / V4L2 controls appended
DEF   FASTRPC_MAX_ATTRIBUTES  ok  count of DSP capability attributes (FASTRPC_IOCTL_GET_DSP_INFO): two appended in K, libadsprpc only asks for ids below the 5.4 count
ENUM  QCA_WLAN_802_11_MODE_INVALID|QCA_WLAN_VENDOR_ATTR_CONCURRENT_STA_POLICY_INVALID  ok  sentinel value after the real members (11BE added before it), never sent

# ---- same bits, other C type
DEF   DRM_FORMAT_BIG_ENDIAN  ok  (1<<31) in 5.4, (1U<<31) in 6.12: the same bit
ENUM  QCA_WLAN_VENDOR_CHANNEL_PROP_FLAG_HE40INTOL  ok  1 << 31 vs 1U << 31: the same bit

# ---- renamed, value checked
ENUM  V4L2_MPEG_VIDEO_BITRATE_MODE_CQ  =V4L2_MPEG_MSM_VIDC_BITRATE_MODE_CQ  the msm CQ (5) is V4L2_MPEG_MSM_VIDC_BITRATE_MODE_CQ in 6.12; upstream's CQ (2) is not used by msm_venc, which keeps 2 = CBR_VFR
ENUM  QCA_WLAN_VENDOR_ATTR_CONFIG_MODULATED_DTIM  =QCA_WLAN_VENDOR_ATTR_CONFIG_DYNAMIC_DTIM  same attribute (1), renamed
ENUM  QCA_WLAN_VENDOR_ATTR_TDLS_NEW_STATE  =QCA_WLAN_VENDOR_ATTR_TDLS_STATE_NEW_STATE  same attribute (2), renamed

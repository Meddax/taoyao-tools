Флешер ядра MeruDevTools для Xiaomi Mi 12 Lite (taoyao), версия 1.2
=====================================================================

Флешер устанавливает на телефон ядро taoyao (файл taoyao-6.12-vX.XX.zip),
которое лежит рядом с ним, — любую версию, без правки скриптов. Копию
разделов телефона (boot, vendor_boot, dtbo), которую делает установщик,
он забирает на компьютер и проверяет (в рекавери LineageOS, crDroid,
Evolution X — ещё до записи ядра), а стоковые образы хранит отдельно —
это ваш путь назад к ядру прошивки. Он же умеет вернуть эти образы.

Флешер сам ничего не записывает в разделы и никогда не запускает fastboot:
ядро ставит установщик из zip ядра, а образы возвращает restore-zip из
копии. На телефоне меняются только boot, vendor_boot и dtbo одного слота
(того, с которого телефон работает); копия разделов остаётся во
внутренней памяти телефона (папка taoyao-6.12-backup) или, в рекавери без
доступа к ней, — в оперативной памяти рекавери до перезагрузки.


1. ЧТО В АРХИВЕ

  run-flash.bat           запуск на Windows (двойной щелчок)
  run-flash.ps1           основная часть для Windows (её запускает run-flash.bat)
  run-flash.sh            запуск на Linux и macOS
  README-flash-ru.txt     эта инструкция
  CHANGELOG-flash-ru.txt  список изменений флешера
  LICENSE-flash.txt       лицензия

  Не открывайте и не сохраняйте скрипты в Блокноте или Word: если файл
  изменился, скачайте архив заново.


2. ЧТО НУЖНО ОДИН РАЗ

  • Кабель USB, который передаёт данные (некоторые кабели только
    заряжают). Лучше подключать прямо к компьютеру, без разветвителя.

  • Разблокированный загрузчик. С заблокированным ядро не ставится: это
    проверяют и флешер, и установщик, и тогда ничего не записывается.

  • Отладка по USB: Настройки → «О телефоне» → 7 раз нажмите на «Версия ОС»
    (HyperOS) или «Номер сборки» (crDroid, Evolution X) → «Для разработчиков»
    (HyperOS: «Расширенные настройки» → «Для разработчиков»; crDroid,
    Evolution X: «Система» → «Для разработчиков») → «Отладка по USB».
    При первом подключении телефон спросит «Разрешить отладку по USB?» —
    отметьте «Всегда разрешать с этого компьютера» и нажмите «Разрешить».

  • Одно из двух:
    а) root для «Оболочки» (Shell) — самый простой способ, а на стоковой
       HyperOS без TWRP / OrangeFox — единственный:
         SukiSU-Ultra / KernelSU / APatch: приложение-менеджер → вкладка
         «Суперпользователь» (APatch: «SuperUser») → в меню ⋮ включите
         показ системных приложений → «Shell» (com.android.shell) →
         включите доступ. Запроса на экране они не показывают: без этой
         настройки su для adb просто не виден (флешер это заметит и
         подскажет).
         Magisk: когда на телефоне появится запрос для Shell — «Разрешить»;
         в настройках Magisk «Доступ суперпользователя» — «Приложения и ADB».
    б) рекавери, которое умеет adb sideload: рекавери LineageOS, crDroid
       или Evolution X (в нём должен работать ADB: Advanced → Enable ADB),
       либо TWRP / OrangeFox. Рекавери Xiaomi такие zip не устанавливает.
       У «user»-сборок рекавери ADB работает без root — что тогда, см.
       раздел 4, пункт «в».

  • Программа adb (Android SDK Platform-Tools от Google). Искать её не
    нужно: если флешер не найдёт adb (или найдёт слишком старый), он сам
    предложит скачать её с сайта Google — около 7–15 МБ, нужен интернет.
    Нажимая Д (или Enter), вы принимаете условия Google:
    https://developer.android.com/studio/terms
    Скачанная программа проверяется (на Windows и macOS — цифровая подпись
    Google; везде — что adb запускается и не слишком старый) и ложится в
    папку platform-tools рядом с флешером, а если туда нельзя писать — в
    папку пользователя:
      Windows: %LOCALAPPDATA%\MeruDevTools\platform-tools
      macOS:   ~/Library/Application Support/MeruDevTools/platform-tools
      Linux:   ~/.local/share/MeruDevTools/platform-tools
    Подойдёт и свой adb: папка platform-tools рядом с флешером, adb в PATH,
    на macOS — brew install --cask android-platform-tools, на Linux —
    пакет adb / android-tools. На Linux скачивание работает на компьютерах
    x86-64, где есть curl (или wget) и unzip (или python3).
    TAOYAO_ADB_DOWNLOAD=1 — скачать без вопроса, TAOYAO_ADB_DOWNLOAD=0 —
    никогда не скачивать.

  • Windows и рекавери (и режим fastboot): если компьютер не видит
    телефон, нужен драйвер Google USB Driver. Это не программа установки,
    а ZIP с файлом android_winusb.inf:
    1) скачайте ZIP: https://developer.android.com/studio/run/win-usb
       и распакуйте его (правой кнопкой → «Извлечь все…»);
    2) откройте Диспетчер устройств (правой кнопкой по «Пуск»), найдите
       устройство с жёлтым значком (Android, taoyao или ADB Interface);
    3) правой кнопкой по нему → «Обновить драйвер» → «Найти драйверы на
       этом компьютере» → «Выбрать драйвер из списка доступных драйверов
       на компьютере» → «Установить с диска…» → «Обзор…» → файл
       android_winusb.inf в распакованной папке → «ОК»;
    4) выберите «Android ADB Interface» (в режиме fastboot — «Android
       Bootloader Interface») → «Далее» → на предупреждение — «Да».

  • Linux: если adb или fastboot пишет «no permissions», установите
    правила udev (Debian/Ubuntu: sudo apt install
    android-sdk-platform-tools-common;
    Fedora: sudo dnf install android-tools; Arch: sudo pacman -S android-udev).


3. КАК ЗАПУСТИТЬ

  Windows 10 и 11:
  • Распакуйте весь ZIP в обычную папку: правой кнопкой по ZIP-файлу →
    «Извлечь все…», например на Рабочий стол. Прямо из ZIP флешер
    не запустится.
  • Положите рядом файл ядра taoyao-6.12-vX.XX.zip (как он скачался, не
    переименовывая).
  • Дважды щёлкните run-flash.bat и выберите пункт меню цифрой. Если
    Windows покажет «Система Windows защитила ваш компьютер» — нажмите
    «Подробнее» → «Выполнить в любом случае».
  • Можно и перетащить zip ядра мышью на run-flash.bat: флешер сразу начнёт
    установку этого файла.
  • Из командной строки или PowerShell в папке флешера:
      .\run-flash.bat install        (или другая команда из раздела 8)
  • Не щёлкайте мышью по окну во время работы: Windows ставит вывод на
    паузу. Если вывод «застыл», нажмите Esc.

  Linux и macOS:
  • Распакуйте ZIP, положите рядом файл ядра, откройте Терминал в этой
    папке и введите:
      bash run-flash.sh              (меню)
      bash run-flash.sh install      (сразу установка)

  Ответы на вопросы флешера: Enter или Д — да; Esc или Н — нет. Если
  включена латинская раскладка: L (клавиша Д) — да, N — нет; на Y флешер
  переспросит — это та же клавиша, что Н, и непонятно, «да» это или «нет».
  Остановить флешер: Ctrl+C — он спросит, точно ли остановиться, и скажет,
  в каком состоянии телефон и что делать дальше. Пока он спрашивает,
  передача файла и копирование на компьютер продолжаются. Идущую установку
  на телефоне флешер никогда не прерывает.

  Меню (нажмите цифру; Esc или Н — то же, что 0):
    1  Установить ядро vX.XX (имя найденного файла ядра)
    2  Вернуть стоковое ядро (копий на компьютере: …)
    3  Вернуть прошлую сборку ядра taoyao (копии в taoyao-<серия>-backups)
       копий на компьютере: …
    4  Только сохранить копию разделов (ничего не записывается)
    5  Выбрать другой файл ядра (найдено: …) — только если рядом их
       несколько
    0  Выход
  Если файла ядра рядом нет, пункт 1 так и пишет: «Установить ядро — файл
  ядра не найден». В меню (а на Windows — и при запуске двойным щелчком
  или перетаскиванием) флешер в конце ждёт: «Нажмите любую клавишу, чтобы
  закрыть окно.»


4. ЧТО БУДЕТ ПРОИСХОДИТЬ

  Флешер всё время следит за телефоном и сам запускает каждую команду, как
  только телефон готов: нажимать Enter на компьютере не нужно. Когда нужно
  что-то нажать на телефоне, он пишет строку, начинающуюся с «>>>», и
  подаёт звуковой сигнал; подсказка повторяется каждые 30 секунд. Шаги
  пронумерованы («Шаг 3 из 7: …») и показывают, сколько примерно займут.

  Способ выбирается сам:

  а) Из работающей системы с root (подходит для любой прошивки, в том
     числе стоковой HyperOS). Флешер отправляет zip ядра на телефон,
     запускает его установщик так же, как это сделало бы приложение-
     установщик, и показывает его сообщения. Всё за один проход: установщик
     сохраняет копию разделов во внутренней памяти
     (/sdcard/taoyao-6.12-backup) и записывает ядро. Установка идёт на
     телефоне отдельно от компьютера: если кабель выпадет, она не
     прервётся, а флешер подождёт и дочитает итог. Потом флешер забирает
     копию на компьютер и предлагает перезагрузку. Перезагружает он так же,
     как перезагрузка из меню кнопки питания: Android сначала закрывает
     приложения и службы, так у него больше времени аккуратно отключить
     /data, и долгая проверка /data при следующей загрузке должна
     случаться реже. Если Android сам перезагрузку не начал, флешер так и
     пишет и перезагружает телефон обычной командой adb reboot.

  б) Через рекавери (adb sideload), если root для Shell нет или телефон уже
     в рекавери. Все вопросы (стоковые образы, версия, KernelSU) флешер
     задаёт ещё в системе, потом спрашивает «Перезагрузить телефон в
     рекавери для установки?» и сам открывает режим Apply from ADB. В
     рекавери LineageOS / crDroid / Evolution X установка идёт в два
     прохода:
       • проход 1 — установщик всё проверяет и делает копию разделов в
         памяти рекавери, ничего не записывая. Рекавери покажет ошибку
         («Installation aborted», статус 1) — так и задумано, не
         перезагружайте телефон;
       • >>> на телефоне: Advanced → Enable ADB — флешер прочитает журнал
         установщика, заберёт копию на компьютер и проверит её;
       • >>> на телефоне снова: Apply update → Apply from ADB — проход 2
         записывает ядро. Флешер запустит его сам, как только телефон
         будет готов.
     Не перезагружайте телефон между проходами: копия из прохода 1 лежит в
     памяти рекавери и пропадёт. Если телефон спросит «Signature
     verification failed. Install anyway?» — выберите Yes.
     TWRP / OrangeFox: флешер сам включает ADB Sideload (если не получится —
     Advanced → ADB Sideload и проведите по полосе). Если TWRP открыл
     внутреннюю память, установка идёт за один проход, копия сохраняется в
     /sdcard/taoyao-6.12-backup.
     Для возврата образов (пункты 2 и 3) без root и для пункта 4 (только
     копия) флешер перезагружает телефон в меню рекавери, а не сразу в
     Apply from ADB: >>> на телефоне Advanced → Enable ADB (TWRP /
     OrangeFox: ничего), и флешер сначала проверит телефон — для возврата
     он сравнит слот до и после, для копии убедится, что рекавери ничего
     не запишет; потом >>> Apply update → Apply from ADB.

  в) Рекавери, у которого ADB работает без root. Так устроены «user»-сборки
     рекавери LineageOS, crDroid и Evolution X: root от SukiSU-Ultra,
     KernelSU или Magisk есть только в загруженной системе, а в рекавери
     его нет, даже с ядром KernelSU. Без root флешер не может прочитать
     журнал установщика и забрать копию разделов. Он это объясняет,
     говорит, что уже сделано с телефоном (обычно — ничего), и предлагает
     по очереди:
       • «Перезагрузить телефон в систему?» — лучший путь: флешер
         перезагрузит телефон, дождётся системы и сделает то же оттуда, с
         root для Shell, за один проход (копия разделов сохранится и на
         компьютере). Если root для Shell нет и там, он подскажет, как его
         включить, и даст проверить ещё раз; обычную установку через это
         рекавери (с чтением журнала) он больше не предлагает — из системы
         возможна только установка через Apply from ADB с проверкой (ниже).
         Если система на телефоне не загружается, ответьте Н;
       • установку через Apply from ADB с проверкой — только если на
         компьютере уже есть проверенная копия этого слота для этой же
         прошивки (флешер её называет: это путь назад; копию той же
         сборки он берёт раньше копии, совпавшей только по отпечатку, а
         про такую копию прямо предупреждает). Флешер отправит
         ядро два раза подряд, без перезагрузки (между ними >>> на
         телефоне снова Apply update → Apply from ADB): первая отправка —
         шаг 1 установщика (копия слота в памяти телефона, ничего не
         записывается), вторая записывает ядро. Копия установщика при этом
         останется только в памяти телефона и пропадёт при перезагрузке.
         Если в этом рекавери открыта внутренняя память или в этом сеансе
         рекавери установщик уже запускали (в памяти телефона есть копия
         слота), установщик может записать ядро сразу: тогда флешер
         отправит ядро один раз и спросит, есть ли на экране строка
         «NOT INSTALLED YET - step 1 of 2». Если проход 1 этого запуска уже
         ушёл в рекавери с открытой внутренней памятью, флешер сначала
         спросит, что на экране, и отправит ядро ещё раз, только если там
         эта строка. Потом он предложит перезагрузку (или попросит выбрать
         Reboot system now), дождётся системы и сравнит версию работающего
         ядра: «Установлено» он пишет, только если работает новое ядро;
       • при возврате образов (пункты 2 и 3) — отправить restore-zip
         выбранной копии через Apply from ADB и так же проверить версию
         ядра после перезагрузки.
     Только копию разделов (пункт 4) через такое рекавери сделать нельзя:
     из системы с root для Shell флешер сам прочитает разделы слота (ничего
     не записывая), заберёт их на компьютер и сделает к копии restore-zip.
     На все вопросы «нет» — флешер останавливается и пишет, что с
     телефоном (обычно «На телефоне ничего не менялось»).

  Перед записью флешер проверяет: модель (только taoyao), загрузчик, слот,
  заряд батареи (ниже 30 % — спросит, ниже 15 % — не продолжит), место на
  компьютере. В режиме Apply from ADB сразу после перезагрузки заглянуть в
  телефон нельзя — тогда модель, загрузчик, слот и место проверяет сам
  установщик (заряд флешер уже проверил в системе). Итог каждого прохода
  флешер читает в журнале установщика на телефоне, а не по сообщениям adb,
  и берёт только журнал этого прохода, а не прошлого.
  Когда передача дошла до 99 %, zip уже на телефоне и работает его
  установщик: флешер ждёт его окончания до 15 минут (строки «… жду»).
  Если передача стоит на месте 5 минут на меньшем проценте, флешер
  считает её оборванной.
  Прерванная передача повторяется сама (до 3 раз), но только если
  установщик точно не запускался; перед повтором второго прохода флешер
  ещё и сверяет разделы слота с копией на компьютере (sha256). Если
  установка оборвалась на середине и слот уже не такой, как копия, флешер
  скажет об этом и предложит сразу, без перезагрузки, вернуть исходные
  образы restore-zip'ом из копии. Если кабель выпадет, пока копия
  переписывается на компьютер, флешер дождётся телефона (подключите кабель
  снова) и скопирует её заново.

  После установки флешер спрашивает «Перезагрузить телефон в систему?» и,
  если вы согласны, ждёт загрузки и проверяет, что телефон запустился с
  новым ядром. Без вашего «да» телефон не перезагружается.


5. НОВАЯ ВЕРСИЯ ЯДРА

  Просто положите новый zip ядра рядом с флешером — флешер обновлять не
  нужно. Если файлов несколько, берётся самый новый по номеру версии (0.19
  новее 0.9, 1.0 новее 0.19; при одинаковом номере — с более новой серией
  ядра: из 6.12 и 6.18 возьмёт 6.18); другой можно выбрать пунктом 5 меню
  или командой install <файл>.
  • Имя файла должно остаться таким, как его выдаёт страница загрузки:
    taoyao-6.12-vX.XX.zip или taoyao-6.12-vX.XX-noksu.zip. Копия, которую
    браузер назвал «… (1).zip», тоже подходит.
  • Флешер сверяет версию в имени с версией внутри файла; если они не
    совпадают (файл переименован или повреждён), он его не берёт.
  • Если рядом лежит файл <имя zip>.sha256, флешер сверит контрольную сумму.
  • Архив-обёртку, в котором лежит zip ядра (так бывает, если скачать
    файлы одним архивом), флешер предложит распаковать.
  • Сборка -noksu — без KernelSU: после неё root пропадёт, и в следующий раз
    флешер будет ставить ядро через рекавери.
  • Если на телефоне уже стоит та же или более новая сборка, флешер
    спросит, точно ли ставить.


6. ГДЕ КОПИИ

  Рядом с флешером (если в его папку нельзя писать — в папке MeruDevTools
  на Рабочем столе, а если Рабочего стола нет — в домашней папке):

  taoyao-stock-images\     СТОКОВЫЕ ОБРАЗЫ — boot, vendor_boot и dtbo
                           прошивки с её собственным ядром. КРАЙНЕ ВАЖНО:
                           храните эту папку, это ваш возврат на стоковое
                           ядро. Сделайте её копию в облако или на флешку.
                           Флешер её никогда не перезаписывает и не удаляет.
                           Внутри — по папке на каждую прошивку и слот
                           (например Evolution_X_16.0-slot_a-20261113-135045):
                           образы, info.txt, restore-zip, его .sha256 и
                           журналы установщика. Одинаковые копии повторно
                           не сохраняются.
  taoyao-<серия>-backups\  копии прошлых сборок ядра taoyao (когда новая
                           сборка ставится поверх старой): у каждой серии
                           ядра своя папка, например taoyao-6.12-backups\
                           v0.18-slot_a-….
  taoyao-6.12-backup-<дата-время>\
                           прочие файлы одного запуска (журналы установщика,
                           журналы неудачной загрузки pstore); пустая папка
                           удаляется сама.
  run-flash.log            журнал флешера.

  На телефоне копии лежат в /sdcard/taoyao-6.12-backup (Внутренняя память →
  taoyao-6.12-backup). Если телефон уже работает на 6.12, а стоковых
  образов на компьютере нет, флешер предупредит: новая копия будет копией
  прошлой сборки, а стоковые образы можно взять только из копии первой
  установки или из самой прошивки.

  От какой сборки прошивки копия, флешер узнаёт по времени сборки
  прошивки (строка rom_build_utc= в info.txt; её пишут установщик 0.20 и
  сам флешер с версии 1.2). Отпечаток прошивки (fingerprint=) для этого не
  годится: модули для Play Integrity подменяют его в работающей системе.
  Копия другой сборки (например, сделанная до обновления прошивки) к
  нынешней прошивке не подходит, и флешер об этом предупреждает. Копии без
  этой строки (их сделали установщик до 0.20 или флешер до 1.2) флешер
  сравнивает по отпечатку и прямо пишет, что это не доказательство; если
  такая копия, по часам телефона, сделана раньше, чем собрана нынешняя
  прошивка, он предупредит, что она, скорее всего, от прошлой сборки
  (кроме копий с датой до 2021 года: часы рекавери обычно не выставлены и
  показывают 1970 год). При возврате копии другой сборки флешер тоже предупреждает:
  restore-zip такой копии откажется записывать, и это нормально.

  Итог в конце работы называет все эти папки и способы вернуться.


7. КАК ВЕРНУТЬСЯ

  • Флешер: пункт 2 меню (стоковое ядро) или 3 (прошлая сборка ядра
    taoyao). Флешер покажет копии на компьютере («Какую копию вернуть?»),
    проверит выбранную (sha256), спросит «Вернуть эту копию в слот …?»,
    вернёт её restore-zip'ом и проверит слот по sha256. На стоковой HyperOS
    без root — как и установка: через TWRP / OrangeFox (флешер спросит,
    стоит ли он у вас). Esc или Н в списке копий и «нет» на вопрос
    «Вернуть эту копию…?» возвращают в меню (при запуске командой
    restore-stock или restore-prev флешер на этом останавливается); на
    телефоне при этом ничего не меняется. Если телефон загружается только
    в рекавери, ADB которого без root, — на вопрос «Перезагрузить телефон
    в систему?» ответьте Н: флешер предложит отправить restore-zip через
    Apply from ADB (раздел 4, пункт «в»).
  • Итог в конце работы флешера печатает команды ниже уже готовыми —
    с полными путями к adb / fastboot и к файлам копии: их можно
    скопировать как есть. Где их вводить: Windows — командная строка
    (Win+R → cmd → Enter; путь в кавычках вставляется правой кнопкой
    мыши); Linux и macOS — Терминал.
  • Вручную в рекавери: Apply update → Apply from ADB (TWRP: Advanced →
    ADB Sideload), затем на компьютере (Windows):
      "<папка флешера>\platform-tools\adb.exe" sideload "<папка копии>\taoyao-restore-<дата>_<слот>.zip"
    Linux и macOS:
      '<папка флешера>/platform-tools/adb' sideload '<папка копии>/taoyao-restore-<дата>_<слот>.zip'
  • Если телефон не загружается: выключите его, зажмите Vol- и Power
    (режим fastboot) и на компьютере введите по очереди (X — слот, a или
    b; Linux и macOS: те же команды с / вместо \ и без .exe):
      "<папка флешера>\platform-tools\fastboot.exe" flash boot_X "<папка копии>\boot.img"
      "<папка флешера>\platform-tools\fastboot.exe" flash vendor_boot_X "<папка копии>\vendor_boot.img"
      "<папка флешера>\platform-tools\fastboot.exe" flash dtbo_X "<папка копии>\dtbo.img"
    Если adb и fastboot в другой папке (флешер скачал их в папку
    пользователя — раздел 2 — или у вас свой adb в PATH), пишите её.
    Windows: если fastboot пишет «waiting for any device», поставьте
    драйвер для режима fastboot (раздел 2).
  • Не загружайте TWRP через fastboot boot на слоте с ядром 6.12 (см.
    «Инструкция по установке.txt», раздел 8.4).

9. ЕСЛИ ЧТО-ТО НЕ ТАК

  • Телефон не найден: кабель, разблокированный экран, «Отладка по USB»;
    в рекавери — Advanced → Enable ADB; на Windows — драйвер (раздел 2).
    Если на экране fastboot — удерживайте питание около 15 секунд.
  • «Компьютер ещё не разрешён» (unauthorized): ответьте «Разрешить» на
    телефоне; не помогло — отзовите разрешения отладки по USB в разделе
    «Для разработчиков» и подключите кабель снова.
  • Рекавери не пускает компьютер по ADB (unauthorized в рекавери): это
    «user»-сборка рекавери. Без ADB флешер не может забрать копию, поэтому
    ничего не записывает. Варианты: установка из системы с root; временно
    рекавери LineageOS или TWRP / OrangeFox; заранее сохранить boot.img,
    vendor_boot.img и dtbo.img из payload.bin своей прошивки.
  • «ADB этого рекавери работает без прав root»: флешер предложит путь
    через систему или установку через Apply from ADB с проверкой (раздел
    4, пункт «в»). Если root для Shell есть, но флешер пишет «su для adb
    не найден» — включите доступ для Shell в приложении root (раздел 2).
  • Рекавери Xiaomi (меню Reboot, Wipe Data, режим подключения к
    компьютеру) не умеет ставить такие zip: нужен root для Shell или
    TWRP / OrangeFox. Если передача не удалась и за 10 минут рекавери так
    и не появилось по ADB, флешер напомнит об этом.
  • Подключено несколько устройств: флешер сам возьмёт Xiaomi Mi 12 Lite,
    если он среди них один, иначе спросит, какое взять: нажмите его цифру;
    Esc или Н — остановиться (на телефоне ничего не меняется).
  • Установщик написал «IPA: ROM not recognised» или «IPA UAPI: … may fail»
    (флешер повторяет такие строки в «Заметках установщика» и пишет, что
    делать): установщик не узнал прошивку и включил режим IPA для
    Evolution X / crDroid. Только на стоковой HyperOS и на прошивке с
    vendor от Xiaomi тогда может не работать точка доступа. Что сделать:
    – установка через рекавери (два шага): пустой файл taoyao-ipa-stock
      должен лежать в /tmp рекавери до шага 2 — файл в /sdcard рекавери
      LineageOS не видит. После шага 1, пока рекавери пускает ADB (до
      того как вы снова выбрали Apply from ADB), выполните в другом окне
      командной строки / Терминала:
        "<папка флешера>\platform-tools\adb.exe" shell touch /tmp/taoyao-ipa-stock
      (Linux и macOS: '<папка флешера>/platform-tools/adb' shell touch
      /tmp/taoyao-ipa-stock). Флешер печатает эту команду с полным путём.
      Уже установили без файла — перезагрузите телефон в рекавери и
      установите ядро заново, положив файл до шага 2;
    – установка из системы с root или в TWRP / OrangeFox с открытой
      внутренней памятью: положите пустой файл taoyao-ipa-stock во
      внутреннюю память (/sdcard) и установите ядро ещё раз.
    Подробно — «Инструкция по установке.txt», раздел 9.
  • Флешер остановился с сообщением — в нём сказано, что случилось и что
    делать; на телефоне в этом случае ничего не записано, если флешер не
    сказал иного. Не перезагружайте телефон, если флешер просит этого не
    делать: копия разделов может быть только в памяти рекавери.
  • Коды выхода (для тех, кто запускает флешер из своих скриптов):
      0   готово (установлено — в том числе если вы остановили флешер уже
          после записи ядра; возвращено, копия сохранена; справка; выход).
          После установки или возврата через Apply from ADB без root —
          только если после перезагрузки работает нужное ядро
      10  остановлено с объяснением, ничего не записано; после установки
          или возврата через Apply from ADB — телефон загрузился с прежним
          ядром
      11  отменено вами
      12  установщик начал запись и вернул исходные образы — слот как был
      13  внимание: состояние слота не подтверждено — смотрите сообщения
          (в том числе: после Apply from ADB телефон не загрузился в
          систему за отведённое время, загрузился с другим ядром или
          слотом, версию ядра не удалось увидеть, или проверку пропустили)
  • Что приложить к сообщению на форуме: файл run-flash.log из папки
    флешера (полный путь флешер пишет в конце).


10. КОНФИДЕНЦИАЛЬНОСТЬ

  В run-flash.log нет серийного номера телефона, имени пользователя и
  имени компьютера, MAC- и IP-адресов (они заменены метками). Журналы
  установщика в папках копий сохраняются как есть; журналы неудачной
  загрузки (pstore) могут содержать серийный номер телефона в строке
  загрузки ядра — не выкладывайте их без просьбы разработчика.
